# Responsible Use

INJECTRIX is a web-application security research and testing toolkit intended
for use on systems you own or are explicitly authorized to test.

By using this software you agree that you will only deploy its active
(payload/request-emitting) capabilities against:

- your own systems and accounts,
- targets covered by a signed engagement scope, or
- programs with published policies that permit the tested class of activity.

The authors accept no liability for misuse. If you find a vulnerability with
this toolkit, disclose it responsibly to the affected vendor.
